# Module 1: Network Basics & Data Transmission

**Date:** 2026-06-02 | **Status:** 🟢 Complete

## 🎯 Core Objective

Build a foundational understanding of networks, connected devices, digital data, and how information is transmitted across a network.

---

## 🌐 Internet & Networks

- The **Internet** is a worldwide collection of interconnected networks.
    
- It is often described as a **network of networks**.
    
- Networks allow devices to communicate, share resources, and access services.
    
- A network can be as small as two connected devices or span the globe.
    

---

## 🏗️ Network Infrastructure

Network infrastructure consists of three major components:

| Component                | Role                          | Examples                             |
| ------------------------ | ----------------------------- | ------------------------------------ |
| **End Devices**          | Source or destination of data | PCs, laptops, smartphones, printers  |
| **Intermediary Devices** | Direct and forward traffic    | Switches, Routers, firewalls |
| **Network Media**        | Carry signals                 | Copper, fiber, wireless              |

- **End devices** interact directly with users and applications.
    
- **Intermediary devices** help data reach its destination.
    
- **Network media** provides the path over which signals travel.
    

---

## 💾 Digital Data

- Computers represent data using **Bits**.
    
- A **bit** has one of two values: `0` or `1`.
    
- A **byte** contains **8 bits**.
    
- Characters, images, audio, video, and other information can all be represented digitally as bits.
    

```text
1 bit  = 0 or 1
1 byte = 8 bits
```

---

## 📡 Data Transmission

Before data can travel across a network, bits are converted into signals.

|Signal Type|Transmission Method|
|---|---|
|Electrical|Electrical pulses through copper|
|Optical|Light pulses through fiber|
|Wireless|Radio/electromagnetic waves through air|

The signal may be converted between different forms as it travels across different types of media.

---

## 📊 Bandwidth, Throughput & Latency

- **Bandwidth:** Maximum capacity of a network connection.
    
- **Throughput:** Actual amount of data transferred over the connection.
    
- **Latency:** Delay involved in moving data from source to destination.
    
- Throughput is affected by traffic, data type, and network latency.
    
- The slowest link along a path can limit overall throughput.
    

---

## 🧠 Exam Highlights

⚠️ **Watch out for**

- Bandwidth is **capacity**, not guaranteed actual performance.
    
- Throughput is the **actual transfer rate**.
    
- Latency measures **delay**, not capacity.
    
- Network media and network types are different concepts.
    
- `8 bits = 1 byte`.
    

💡 **Key Takeaways**

- The Internet is a **network of networks**.
    
- Network communication requires **devices + intermediary infrastructure + media**.
    
- All digital information can ultimately be represented as **bits**.
    
- Bits are transmitted as electrical, optical, or wireless signals.
