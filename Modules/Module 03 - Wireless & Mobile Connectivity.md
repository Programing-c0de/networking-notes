# Module 3: Wireless & Mobile Connectivity

**Date:** 2026-06-02 | **Status:** 🟢 Complete

## 🎯 Core Objective

Understand how mobile devices connect to networks and peripherals using Wi-Fi, cellular, Bluetooth, GPS, and NFC.

---

## 📡 Wireless Technologies

|Technology|Primary Role|
|---|---|
|**Wi-Fi**|Local network connectivity|
|**Cellular**|Wide-area network connectivity|
|**Bluetooth**|Short-range device connectivity|
|**GPS**|Location / positioning|
|**NFC**|Very short-range communication|

A mobile device can use several of these technologies simultaneously.

---

## 📶 Wi-Fi

- **Wi-Fi** allows mobile devices to connect to wireless LANs.
    
- When available, Wi-Fi can be used instead of cellular data for Internet access.
    
- Wi-Fi generally consumes less power than cellular connectivity.
    
- Secure Wi-Fi networks should use modern encryption such as **WPA2 or newer**.
    

### Wi-Fi Identification

- **SSID:** Name of the wireless network.
    
- **Passphrase:** Password used to authenticate to the network.
    

When connecting manually, the SSID and security credentials must match the wireless network configuration.

---

## 📱 Cellular Connectivity

- Cellular networks provide connectivity over large geographic areas.
    
- A mobile device can transition between different cellular coverage areas.
    
- If configured, a device can use cellular data when Wi-Fi is unavailable.
    

```text
Wi-Fi available
      ↓
Use Wi-Fi
      ↓
Wi-Fi unavailable
      ↓
Use cellular data
```

---

## 🟦 Bluetooth

**Bluetooth** provides short-range, low-power communication between devices.

Common uses include:

- Headsets
    
- Keyboards and mice
    
- Speakers
    
- Car audio
    
- Tethering
    

### Bluetooth Pairing

1. Enable Bluetooth.
    
2. Make the device discoverable if required.
    
3. Scan for nearby devices.
    
4. Select the device.
    
5. Enter a PIN/passkey if required.
    
6. Establish the connection.
    

---

## 🔗 Tethering

**Tethering** allows a device to share its network connection with another device.

Possible methods include:

- Bluetooth
    
- Wi-Fi
    
- USB
    

---

## 📍 GPS & NFC

- **GPS:** Used to determine geographic location.
    
- **NFC:** Enables communication over very short distances.
    

These technologies serve different purposes from Wi-Fi and cellular networking.

---

## 🧠 Exam Highlights

⚠️ **Watch out for**

- **SSID ≠ password.**
    
- Wi-Fi provides network access; GPS provides location.
    
- Bluetooth is designed for short-range, low-power communication.
    
- Bluetooth pairing is different from connecting to a Wi-Fi network.
    
- Cellular and Wi-Fi can provide Internet connectivity, but they use different network infrastructures.
    

💡 **Key Takeaways**

- **Wi-Fi → local connectivity.**
    
- **Cellular → wide-area connectivity.**
    
- **Bluetooth → peripherals and short-range devices.**
    
- **GPS → positioning.**
    
- **NFC → very short-range communication.**
    
- A smartphone can use multiple wireless technologies at the same time.
